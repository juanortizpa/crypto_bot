MACHINE LEARNING

¿Clasificación o regresión? Elegimos clasificación binaria.

PREGUNTA DE MODELADO
¿Esta operación cerrará en WIN (+3%) o en LOSS (–2.5%) antes de N horas?
VARIABLES PREDICTORAS (X)

13 factores del gate(M1–M3, S1–S4, T1–T2, R1–R2, N1)

Indicadores técnicosRSI, MACD, ATR, BB width, OBV

Contexto macroFear&Greed, BTC dominance, vol regime

VARIABLE OBJETIVO (y)

y = outcome

1 → la posición cerró en WIN

0 → la posición cerró en LOSS

Es clasificación binaria.

Métrica primaria: Win Rate (= accuracy de clase WIN)

from sklearn.tree import DecisionTreeClassifier
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score, classification_report

# 1. Cargar features y target
X = df[gate_factors + tech_indicators]
y = df["outcome"]   # 1 = WIN, 0 = LOSS

# 2. Train / Test split (80/20, estratificado)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=42)

# 3. Modelo (interpretable, resistente a overfitting)
model = DecisionTreeClassifier(max_depth=5, random_state=42)
model.fit(X_train, y_train)

# 4. Evaluación
y_pred = model.predict(X_test)
print(f"Accuracy: {accuracy_score(y_test, y_pred):.2%}")

LIMITACIONES

Lo que este bot NO puede hacer

Honestidad técnica: ningún modelo es perfecto. Estas son las fronteras reales del sistema.
Solo TOP 20 pares
Entrenado con BTC, ETH y 18 más. Aplicarlo a memecoins random degrada el win rate.
Spreads y slippage no modelados
Las métricas asumen ejecución al precio de cierre. En mainnet el P&L real puede ser 0.1–0.3% menor por operación.
Dependencia de Google News RSS
Si el RSS cae o sufre delay > 5 min, N1 se queda obsoleto y el bot opera con sentimiento estale.
No detecta black swans
Quiebra de exchange, hack de Binance, flash crash. Ningún feature histórico los predice.
Régimen-dependiente
Bull market 2024 ≠ bear market hipotético. Hay que re-validar si la volatilidad estructural cambia.
Sin protección contra correlación
Si abre 5 trades en altcoins y BTC se desploma, las 5 cierran en LOSS al mismo tiempo.
