DINERO REAL

Conectar tu cuenta de Binance

Cinco pasos. Las claves se guardan cifradas en GitHub, en el mismo lugar donde ya corre la simulación gratis. Esta página nunca te las pide ni las ve.

Crea una clave de API en Binance

  1. Entra a Binance → tu perfil → Gestión de API.
  2. Crea una clave generada por el sistema y ponle un nombre, por ejemplo bot-rotacion.
  3. En Editar restricciones activa Habilitar trading Spot y Margin.
  4. Deja desactivado «Habilitar retiros». Con eso la clave puede comprar y vender, pero no sacar dinero.
  5. Copia la API Key y la Secret Key. La secreta solo se muestra una vez.
Si Binance te exige una lista de IP fijas para activar el trading, déjala en blanco hasta saber desde qué servidor operará el bot (paso 4).
Abrir Gestión de API en Binance

Guarda las dos claves en GitHub

Crea dos «secretos» con estos nombres exactos y pega cada clave como valor. Una vez guardados nadie puede leerlos, ni siquiera tú: solo el bot al ejecutarse.

Enciende el modo real

Cuando la prueba salga completa, crea la variable de abajo con el valor live. Desde el siguiente ciclo diario el bot opera con dinero real y aquí aparece la pestaña «Dinero real». La simulación sigue corriendo en paralelo para comparar.

  • Pausar: cambia ROT_MODE a paper. Lo que esté comprado se queda en tu cuenta.
  • Salir del todo: cambia ROT_MODE a salir. En el siguiente ciclo vende todo a USDT y se detiene.
  • Mostrar montos: por privacidad el panel real muestra solo porcentajes. Para ver dólares crea la variable ROT_MOSTRAR_MONTOS con valor si (serán públicos).
Este panel solo lee los archivos que el bot publica una vez al día en la rama paper-state del repositorio. No es asesoría financiera.
